# 金融證照模擬測驗

證券、期貨證照考試的互動模擬測驗，一份證照一個單檔 HTML，開了就能練。

👉 **<https://bobe2510.github.io/finance-exam-quiz/>**

| 測驗 | 題數 | 科目 |
|---|---|---|
| [證券商業務員（初業）](chuye.html) | 917 | 證券交易相關法規與實務／證券投資與財務分析 |
| [證券商高級業務員（高業）](gaoye.html) | 1,651 | 證券交易相關法規與實務／投資學／財務分析 |
| [期貨商業務員](qihuo.html) | 970 | 期貨交易法規／期貨交易理論與實務 |
| [金融市場常識與職業道德](ethics.html) | 1,120 | 共同科目固定題庫 |

## 功能

- 依科目與章節勾選練習範圍，題數 10／20／30／50／全部
- **出題頻率篩選**：🔥 高頻（同題或同考點出現 2 次以上）、🔥🔥 超高頻（3 次以上），可與章節範圍疊加——時間不夠時先練這些
- 出題方式：隨機、未練習優先、依題號順序、錯題本、已標記
- 選項可每次隨機打亂，解析裡的 ①②③④ 會跟著對位
- 答題後顯示解析、口訣，以及**每個選項為什麼對或錯**
- 錯題本（連續答對 2 次才移出）、☆ 標記、各章正確率統計
- 深淺色主題、鍵盤快捷鍵、手機版面
- 進度存在瀏覽器 localStorage，可匯出／匯入 JSON 備份

每個 HTML 都是單檔、無外部依賴，另存到本機後可完全離線使用。
手機建議用 Safari／Chrome 開啟後「加入主畫面」。

## 關於答案與解析

題目與答案取自阿摩線上測驗的歷屆試卷存檔，**答案是依作答者投票統計取最高票，不是主辦單位公布的官方答案**。
解析為自行撰寫，4,658 題全部附有逐選項辨析。法規部分以全國法規資料庫條文為準，
但法規會修正、題庫也可能與現行規定衝突，**純數值型的法規題請再與現行規定核對**。
解析中標有 ⚠️ 的地方，是提醒該處為純數值規定、或題庫原文有缺漏／與條文用語不一致之處。

僅供個人備考練習使用。
